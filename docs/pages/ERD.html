Entities & Schema Overview

Entity Primary Key Foreign Keys / References Description
Student student_id employment_place → EmploymentPlace.place_name Stores trainee profile, academic performance (GPA, credits), contact details, and department.
InternshipCycle cycle_id student_id → Student.student_id
professor_id → SupervisingProfessor.professor_id
place_name → EmploymentPlace.place_name 		Connects a student, supervising professor, and host workplace for a specific semester and year.
SupervisingProfessor professor_id None Maintains faculty coordinator profiles, university emails, and academic departments.
EmploymentPlace place_name None Stores external training organizations, coordination contact numbers, and available departments.

Key Relationships

  • Supervision: A SupervisingProfessor supervises one or more InternshipCycle sessions.
  • Hosting: An EmploymentPlace hosts one or more InternshipCycle placements.
  • Participation: A Student is linked to their training cycle via InternshipCycle and references their host organization in employment_place.

These stories, including creating company-specific internship channels, prompting for notification permissions, and viewing internship site reviews, were added post-Phase 2 to enhance communication, user engagement, and feedback mechanisms within the internship management system

# Scope changes

This file records the changes to our agreed stories after the Phase 2 backlog: what changed, why, and what happened to the story.

## #39 — Create Company-Specific Internship Channels
- **Change:** Rewritten after instructor feedback on the Phase 2 backlog. Reduced to a simpler version: a channel is created for each company; messaging inside the channels is not included.
- **Why:** The original story was too broad to finish in one sprint.
- **Result:** Built and closed in Phase 3.

## #41 — Prompt for Notification Permissions
- **Change:** After instructor feedback on the Phase 2 backlog it was first set to be dropped as out of scope. The team then kept it and rewrote its acceptance criteria to name the STUDENT table, the notification preference value and the error message.
- **Why:** The original criteria were not testable.
- **Result:** Built and closed in Phase 3.

## #43 — View Internship Site Reviews
- **Change:** Rewritten after instructor feedback on the Phase 2 backlog. The acceptance criteria now name the EmploymentPlace and InternshipEvaluation tables, the average site_rating, the sort order, hiding the reviewer's identity, and the empty and error messages.
- **Why:** The original criteria were not testable.
- **Result:** Built and closed in Phase 3.

## #48 — Manage Internship Company Requirements
- **Change:** Removed from scope; the issue was closed as not planned.
- **Why:** Not planned for this release
- **Result:** Not built.
